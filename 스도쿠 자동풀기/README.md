# 스도쿠 자동풀기

백준 [2580번 스도쿠](https://www.acmicpc.net/problem/2580) 문제를 C++로 풀었던 경험을 살려, 직접 숫자를 입력하면 자동으로 풀어 주는 GUI 프로그램으로 확장했습니다.

## 핵심 기능

### 스도쿠 자동 풀이
- 행·열·3×3 칸에 이미 쓰인 숫자를 기록해 두고 백트래킹으로 빈칸을 채웁니다.
- 처음부터 규칙에 어긋나거나 풀 수 없는 문제는 "풀 수 없는 문제입니다!" 알림을 띄웁니다.

### 보기 쉬운 입력판
- 81칸을 `Entry`로 만들어 숫자를 입력받습니다.
- 3×3 칸마다 (행/3 + 열/3)의 홀짝으로 배경색을 번갈아 칠해 구역을 구분했습니다.
- 처음에는 빈칸에 0이 미리 들어가 있어 불편했는데, 빈칸으로 두고 내부에서만 0으로 처리하도록 고쳤습니다.

## 실행 방법

```
python sudokugui.py
```

Python이 없으면 `sudoku.exe`를 바로 실행하면 됩니다.

## 배운 점

이전 반응속도 테스트 프로그램에서는 해 보지 못했던 class와 GUI 위젯을 함께 쓰는 구조를 처음 만들어 봤습니다. C++ 코드를 Python으로 옮기는 과정에서 버그가 많아 포기하고 싶기도 했지만, 여러 자료를 찾아가며 끝까지 완성할 수 있었습니다.
