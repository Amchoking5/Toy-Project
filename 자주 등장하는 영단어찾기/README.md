# 자주 등장하는 영단어 찾기

수능을 준비하던 군대 동기의 아이디어로 만든 프로그램입니다. 영어 지문에서 단어를 뽑아 등장 횟수 순으로 정렬하고, 자주 나오는 단어를 단어장처럼 외우고 복습할 수 있게 했습니다.

## 핵심 기능

### 빈출 단어 추출
- `english.txt`에 지문을 넣으면 한글·숫자·기호를 걸러 내고 영어 단어만 소문자로 뽑습니다.
- 딕셔너리로 단어별 등장 횟수를 세고, 많이 나온 순서로 정렬합니다.
- 한 글자 단어, 대명사, 쉬운 동사처럼 외울 필요가 없는 단어는 `baned.txt`로 걸러 냅니다.

### 단어장 복습
- 단어장(`bestword.txt`)에 있는 단어가 다시 나오면 뜻을 물어보고 정답을 확인합니다.
- 뜻을 맞히면 그 단어를 단어장에서 빼고 `baned.txt`로 옮길 수 있습니다.
- 처음 나온 단어는 단어장에 추가할지 제외할지 고를 수 있고, "뜻 검색하기" 버튼으로 바로 검색할 수 있습니다.

## 실행 방법

같은 폴더에 `english.txt`(지문), `baned.txt`(제외 단어), `bestword.txt`(단어장)를 두고 실행합니다.

```
python "수능 영단어 찾기.py"
```
