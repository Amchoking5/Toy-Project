# 스도쿠 웹 풀이

[스도쿠 자동풀기](../스도쿠%20자동풀기)(tkinter)를 웹으로 옮긴 프로젝트입니다. 서버 없이 정적 페이지만으로 동작해서, 설치 없이 브라우저에서 숫자를 입력하거나 스도쿠 사진을 올려 바로 풀 수 있습니다.

## 핵심 기능

### 빠른 풀이 엔진
- 스도쿠를 정확 덮개(exact cover) 문제로 보고, '칸마다 숫자 하나'와 '행·열·3×3마다 숫자 v는 한 번' 제약 중 선택지가 가장 적은 것부터 시도합니다 (Algorithm X 방식).
- 단순 백트래킹으로는 수백만 번 시도해도 판정하지 못하던 '풀 수 없는 문제'를 수백 번 만에 판정합니다.
- 행·열·3×3의 사용 숫자를 비트마스크로 관리해 후보 계산을 빠르게 했습니다.

### 입력과 검사
- 칸을 누르면 그 칸을 둘러싸고 1~9, 힌트(💡), 지우기(⌫) 버튼이 원형으로 펼쳐집니다. 같은 행·열·3×3에 이미 있는 숫자는 흐리게 표시합니다.
- 키보드(숫자, 방향키, Backspace)로도 입력할 수 있습니다.
- 같은 행·열·3×3에 겹치는 숫자를 입력 즉시 빨간색으로 표시합니다.
- 선택한 칸의 행·열·3×3과 같은 숫자를 강조해 보기 쉽게 했습니다.

### 힌트
- 원형 선택창의 💡를 누르면 지금 입력한 숫자들로 문제를 풀어 보고, 그 칸의 정답만 채워 줍니다.
- 힌트로 채운 칸은 초록색으로 구분하고, 사용한 힌트 횟수를 보여 줍니다.
- 입력이 겹치거나 풀 수 없는 상태면 힌트 대신 그 이유를 알려 줍니다.

### 사진으로 판 불러오기
- 사진을 올리면 적응형 이진화로 잉크를 골라내고, 크고 정사각형에 가까운 덩어리들을 판 후보로 뽑습니다.
- 후보마다 네 꼭짓점으로 원근 보정해 정사각형으로 편 뒤, 1/9 간격 격자선과 얼마나 맞는지 점수를 매겨 진짜 판을 고릅니다. 종이 테두리나 그림자 경계를 판으로 착각하지 않게 하기 위해서입니다.
- 81칸에서 숫자가 있는 칸만 골라 Tesseract.js로 판독하고, 확신이 낮은 칸은 주황 테두리로 표시해 사용자가 확인하게 합니다.
- 사진은 서버로 보내지 않고 브라우저 안에서만 처리합니다. 인식 엔진(약 7MB)은 처음 업로드할 때만 내려받습니다.
- 합성한 테스트 사진 6장(정면 캡처 3장, 기울어지고 그림자 진 사진 3장)에서 486칸 중 485칸을 맞혔고, 틀린 1칸도 주황 테두리로 표시되었습니다.
